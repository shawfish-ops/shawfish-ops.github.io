Privacy Policy

Last updated: October 5, 2026

OpenClaw gog is a private tool used only by its developer to access the developer's own Google account data. It is not available to the public.

Data accessed

With the account owner's consent, the app accesses Google user data in the scopes granted at sign-in (such as Gmail, Calendar, Drive, Sheets and Tasks) solely to perform actions the account owner requests.

Storage and sharing

OAuth tokens are stored locally in the owner's system keychain. Data is processed on the owner's own computer and is not sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
